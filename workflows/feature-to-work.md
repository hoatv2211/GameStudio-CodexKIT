# Feature idea → Work packets

1. Use `game-feature-brainstorming` for 2–3 options and trade-offs.
2. Use `game-feature-to-spec` for purpose, I/O, edge cases, tuning and playtest criteria.
3. Use `feature-to-work-packets` for exact paths, owners, dependencies and checks.
4. Use `review-swarm` read-only before integration when risk or scope requires it.

This entry point contains no duplicated workflow implementation.
